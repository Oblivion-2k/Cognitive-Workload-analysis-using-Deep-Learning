# Cognitive Workload Analysis using Deep Learning

This project performs cognitive workload classification using EEG signals from the STEW dataset.

Dataset
- 48 subjects
- High workload and Low workload EEG recordings
- Sampling rate: 128 Hz

Pipeline
1. EEG preprocessing
2. Bandpass filtering
3. Data Standardization
4. Model Training
5. Cross Validation

Models
- 1D CNN
- BiLSTM

Libraries
Python, MNE, TensorFlow, Scikit-Learn
